# LibTV（复刻项目）

复刻 LiblibAI 旗下专业 AI 视频创作平台 **LibTV**（liblib.tv）：以「无限画布 + 节点式工作流」为核心范式，将剧本、分镜、图像、视频、音频统一为画布上可编排、可复用的节点，支撑从剧本到成片的全流程创作，并同时面向人类创作者与 AI Agent（Skill/CLI）两类入口。

功能规格依据官方《LibTV 使用指南》整理。

## 技术栈

- Next.js (App Router) + TypeScript + Tailwind CSS
- [@xyflow/react](https://reactflow.dev)（React Flow）— 无限画布与节点编排
- Zustand — 画布状态管理

## 当前进度：Phase 2 — 全功能创作闭环

### 生成架构（Phase 1）

- ✅ **Provider 抽象层**：统一生成接口（`createTask` / `getTask` / `capabilities`），画布节点只跟统一接口对话。已接入 Mock、火山方舟（即梦）、可灵 Kling、本地 ffmpeg 四个 Provider。
- ✅ **能力声明式注册**（`src/lib/providers/catalog.ts`）：模型声明支持的模式与参数范围，驱动前端下拉/参数面板/连线校验与服务端请求校验 —— 从根本上消灭「参数不合法被上游打回」一类 Bug。
- ✅ **请求校验**（zod + 能力声明）：不合法请求不发往上游，错误信息是中文人话。
- ✅ **异步任务中枢**（`src/lib/tasks`）：文件持久化 `TaskStore` + 集中式指数退避轮询器 + **SSE** 实时状态流（排队→生成中(xx%)→完成）。
- ✅ **产物转存**：完成即把时效 URL 下载到 `public/generated/`；转存失败保留原始地址不丢结果。
- ✅ **密钥安全**：Key 仅存服务端，可灵 JWT 服务端签发，浏览器永不接触；未配置的模型前端置灰。
- ✅ **失败可重试 / 崩溃恢复**：上游错误翻译为明确提示 + 一键重试；重启后恢复进行中任务。

### 创作闭环（Phase 2）

- ✅ **文件上传**：图片/视频/音频拖入画布即建节点，也可右键/侧栏上传（类型与大小服务端校验）。
- ✅ **画布持久化**：节点与连线存 localStorage，刷新不丢；进行中的生成任务刷新后自动重连恢复。
- ✅ **真实 LLM 文本/脚本**：豆包 Seed（方舟 LLM，复用 `ARK_API_KEY`）驱动文本节点与**结构化分镜脚本**生成；文本节点也支持手动编写。
- ✅ **脚本流水线**：分镜表格可编辑、可勾选 → 「生成分镜图」批量出图（自动建节点+连线）→ 「批量生成视频」图生视频，全自动编排。
- ✅ **整组执行**：框选多节点一键按拓扑顺序整组重跑（上游完成才轮到下游）。
- ✅ **视频合成（真 ffmpeg）**：选中多个视频（可带一条音频做 BGM）一键创建合成节点，按画布顺序拼接、统一分辨率/帧率、混音导出 mp4 —— 依赖内置静态 ffmpeg，无需额外安装。
- ✅ **节点右键菜单**：副本（带连线）/ 复制粘贴（Ctrl+C/V，不带连线）/ 保存为资产 / 删除。
- ✅ **我的资产 + 历史记录**：左侧栏管理复用资产；所有生成历史可浏览并一键发送回画布。
- ✅ **Slash 快捷指令**：图像节点有参考图时输入 `/` 唤出多机位九宫格、剧情推演四宫格、25 宫格连贯分镜、光影矫正、角色三视图、画面推演等预设。
- ✅ **测试**：49 个用例 —— Provider 契约测试、JWT、ffmpeg 命令构造 + 真实合成集成测试、任务中枢全链路、画布编排（流水线/拓扑执行/合成顺序）。

### 接入真实模型（配好 Key 即用）

复制 `.env.example` 为 `.env.local` 填入密钥（不配也能用 Mock 全功能离线运行）：

| Provider | 驱动的能力 | 鉴权 |
|---|---|---|
| 火山方舟 | Seedream 4.0 生图、Seedance 视频、豆包 LLM（文本/分镜脚本） | `ARK_API_KEY`（一个 Key 全包） |
| 可灵 Kling | kling-v2-5-turbo 视频（文生/图生/首尾帧）、Kling 生图 | `KLING_ACCESS_KEY` / `KLING_SECRET_KEY` |
| 本地 ffmpeg | 视频合成（拼接 + BGM 混音） | 无需配置，依赖自带 |

> 新接一家平台：实现 `GenerationProvider`、在 `catalog.ts` 声明能力、在 `registry.ts` 登记，三步即可，画布与任务中枢无需改动。

## 路线图

- ✅ **Phase 1**：生成 Provider 抽象层 + 异步任务中枢，接入可灵 / 即梦
- ✅ **Phase 2**：上传 / 持久化 / 右键菜单 / 脚本流水线 / 整组执行 / 视频合成 / 资产与历史 / Slash 指令

## 本地运行

```bash
npm install
npm run dev          # 开发服务器
npm test             # 契约 + 集成测试
npm run typecheck    # 类型检查
```

打开 http://localhost:3000，双击画布空白处即可开始创建节点。无需任何密钥即可用 Mock Provider 跑通完整链路。
