# LibTV（复刻项目）

复刻 LiblibAI 旗下专业 AI 视频创作平台 **LibTV**（liblib.tv）：以「无限画布 + 节点式工作流」为核心范式，将剧本、分镜、图像、视频、音频统一为画布上可编排、可复用的节点，支撑从剧本到成片的全流程创作，并同时面向人类创作者与 AI Agent（Skill/CLI）两类入口。

功能规格依据官方《LibTV 使用指南》整理。

## 技术栈

- Next.js (App Router) + TypeScript + Tailwind CSS
- [@xyflow/react](https://reactflow.dev)（React Flow）— 无限画布与节点编排
- Zustand — 画布状态管理

## 当前进度：Phase 0 — 可运行的无限画布骨架

- ✅ 无限画布：缩放（最低 10%）、平移、小地图、点状网格
- ✅ 五大基础节点：文本 📝 / 图片 🖼️ / 视频 🎥 / 音频 🎵 / 脚本 🎬
- ✅ 双击画布空白处新建节点；左侧工具栏快捷添加
- ✅ 节点连线搭建工作流，上游已完成节点的内容会作为下游生成的参考上下文
- ✅ 每个节点内置生成器：提示词 + 模型选择 + 生成按钮（当前为 mock API：`/api/generate`）
- ✅ 脚本节点以分镜表格（场景/景别/画面描述/运镜）展示生成结果

## 路线图

- **Phase 1**：节点能力补全 — 文件拖入上传、节点右键菜单（副本/资产）、脚本→批量分镜图→批量视频流水线
- **Phase 2**：生成 Provider 抽象层，接入真实文生图 / 图生视频 / TTS 模型
- **Phase 3**：高级控件 — 打组与整组执行、分镜组宫格、多角度/打光/摄像机参数、九宫格 Slash 指令
- **Phase 4**：视频合成时间轴、导演台（3D 构图）、Skill API（Agent 入口）

## 本地运行

```bash
npm install
npm run dev
```

打开 http://localhost:3000，双击画布空白处即可开始创建节点。
